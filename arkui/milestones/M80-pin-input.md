# M80 · Flutter PIN 输入兼容

Flutter PIN 对话框使用文本输入，随机 PIN 也可包含字母；原生发送确认和设置却使用数字键盘且限制 12 位，无法输入部分有效 PIN。两处改为密码输入，允许字母等完整内容，提供显示/隐藏按钮，不再限制 12 位。

发送 PIN 独立为组件，取消或提交时清空输入；空值不能点确认，取消仍终止发送。键盘确认可提交。再次收到 401 时显示错误提示，新请求和提交后清除该状态。输入方向固定为 LTR，包含读屏标签。

真实 HTTP 对端测试验证错误 PIN 后重试、超过 12 位且含字母/符号/中文的 PIN 完整通过 URL 编码、正确后完成、取消不提交空 PIN、新请求无旧错误。服务集成回归和 ArkTS/原生未签名构建通过。未访问设备，键盘及读屏实机交互待检查。
