# M97 · 消息草稿按本次任务清理

消息页此前按首个附件 ID 查询成功记录。相同附件已有成功任务，而本次 send 因证书重置或并发限制未启动时，可能误认旧任务并清空草稿。

改用 LocalSendService.send 返回的本次任务 ID；只有非空 ID 对应的任务 complete 才清理草稿，其他结果保留。发送服务已有明确空返回和唯一任务返回，本轮仅修正界面的结果关联。

验证：消息状态、成功选择清理两个主机测试通过，最终 ArkTS 未签名构建成功。代码审查确认身份重置、空选择及并发上限均返回空 ID；主机测试不等于 ArkUI 草稿界面运行测试，相关重复发送场景仍待实机验收。未访问设备。
