# M63 · 自动名称与自定义收藏备注

对照 Flutter 的收藏编辑和 `RegisterDeviceAction`，增加 `customAlias` 标记。新收藏默认跟随设备名称；手动改名后保留备注。即使端点不变，已确认的设备信息也能更新自动名称。

Flutter 首次导入保留原 `customAlias`。旧原生收藏没有标记，无法可靠判断名称是否手填，因此按自定义备注保留。后续编辑地址不会清除标记。

收藏信息在成功的 HTTP 端点探测或 TLS 身份验证后更新。UDP 通告不直接改写收藏；不同指纹不能替换已有身份，HTTP 不能将 HTTPS 收藏降级。
