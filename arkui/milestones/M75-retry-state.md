# M75 · 重试状态与重复点击

旧失败任务的重试按钮始终可用，快速点击或在新任务完成后再次点击旧任务，都会重复发送同一批未完成文件。

现在旧任务在重试期间显示禁用的“正在重试”，服务也检查这一状态，阻止重复调用。发送方法返回实际创建的任务 ID；创建任务后，旧任务记录关联并显示“已在新任务中重试”。后续失败可从新任务继续重试。若因证书重置、并发上限或无文件而没有创建任务，旧入口仍可重试。等待中、传输中以及非发送任务不会触发重试。列表已淘汰的旧任务不会被重试收尾重新插入。

服务集成测试通过，覆盖首次部分失败、阻止启动后恢复、同时两次重试仅一项上传、完成后旧入口不重复发送，以及原有多设备队列快照。取消、消息状态和部分接收三个测试文件也通过。ArkTS 与原生未签名构建成功。未访问设备；不是 Flutter 同会话单文件重试的完全复刻，原生仍创建一个仅含未完成文件的新任务。
