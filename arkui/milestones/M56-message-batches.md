# M56 · 会话中的多文件批次

同一设备、方向和传输 ID 下的多个文件合并为一个消息块，显示文件数、总大小、完成数量和批次状态，默认预览前三项。完整文件列表在详情中按 50 项展开，保留每项的详情、打开、分享、再次发送和删除等实际可用操作；传输中保留任务入口。

先分组再搜索和分页。搜索命中一个文件时保留整个批次，历史分页也不拆开批次。文字消息继续独立显示。会话计数和新消息提示按批次计数，状态更新不触发新消息提示。

新的 Flutter 导入记录保留原批次 ID；较早版本已导入且仍带明确批次 ID 的消息记录可直接分组。缺少可靠批次身份的旧历史保持独立，不按时间或同名设备猜测合并。

验证：会话专项覆盖设备、方向和传输隔离，搜索上下文，文字/旧历史兼容，部分完成和失败优先级，新消息计数；Flutter 导入回归通过。ArkTS 编译和未签名打包通过。未使用设备，具体尺寸与交互观感仍待用户检查。
