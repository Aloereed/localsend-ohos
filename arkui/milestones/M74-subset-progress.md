# M74 · 部分接收的进度统计

对方只接受部分文件时，旧发送端直到逐个遍历到缺少令牌的文件才标记跳过，而且没有更新选择状态。总大小包含跳过文件，传输完成后可能同时出现 100%、不相等的已传/总字节和剩余时间。

现在收到上传令牌清单后、进入传输状态前，就确定所有文件的接受与跳过状态。204 文字预览确认同样将未接收的附件排除。进度统计仅包含已选择且未跳过的文件；只有传输进行中才显示剩余时间。与 Flutter `progress_page.dart` 按非 skipped 文件计算 `_selectedFiles` 和 `_totalBytes` 的行为对齐。

新增真实 HTTP 对端集成测试，只接受 5 字节文字而跳过 3 GiB 文件，验证首次上传完成之前分母已为 5、跳过文件不被打开、结束时总字节一致。204 预览确认不产生上传请求。另测进行中、等待、完成、取消、拒绝及失败的剩余时间边界。
