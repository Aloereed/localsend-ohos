# M108 · 设置与历史写入顺序

普通保存和恢复设置通过同一持久化队列执行，避免并发异步 put 中旧设置晚完成、覆盖较新的值。每轮普通保存开始时一次性序列化当前设置、收藏和允许持久化的历史，再依次写入并 flush；队列中一次失败不会阻止后续保存。

恢复设置的写入、内存更新和失败回滚都在队列操作内，实际执行前重新检查传输/浏览器活动。后续保存读取恢复后的状态，保留设备指纹和既有隐私历史规则。

验证：延迟旧写入的测试覆盖最新值、无重叠 put、私有记录排除、失败后恢复、保存/恢复/再保存顺序，以及排队期间开始分享后拒绝恢复。累计 53 个主机测试全部通过（13.7 秒），新增活动重查断言单独复测通过；最终 ArkTS 未签名构建成功。未访问设备，实际存储介质故障与进程终止恢复仍不能由主机测试完全证明。
