# M110 · 网络输入严格校验

原组播校验先 Number 转换地址段，空段会变成零，导致 224..0.167 等无效输入通过。现在复用严格 IPv4 语法检查，再验证 224–239 首段范围，合法输入去除首尾空白并规范化前导零。

端口和发现超时只接受十进制整数文本，范围限制不变。有效网络输入清除旧校验错误，再按 M109 保存结果反馈。无效输入在修改设置前返回。

测试覆盖默认值、上下边界、空段、空白段、符号、科学计数法、越界和 IPv6；通过。最终 ArkTS 未签名构建成功。未访问设备，本轮验证输入处理，不等于对所有自定义组播网络的发现保证。
