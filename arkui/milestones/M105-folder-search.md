# M105 · 自定义目录选择器搜索

下载目录选择器支持搜索当前目录的全部可见子文件夹，再按 50 项分页。搜索忽略首尾空白和大小写，切换目录清空搜索；无子文件夹与搜索无匹配分别显示。加载或读取错误时禁用搜索，当前目录仍由原有选择按钮确认。

空初始路径及应用下载范围之外的初始路径回到应用下载根目录，避免留在空路径且确认按钮可用的状态。范围内但不存在或不可读的路径仍展示错误和重新读取入口。

Flutter 备用选择器没有创建目录操作，本次属于目录定位体验完善。目录选择与语言回归通过，最终 ArkTS 未签名构建成功；主机回归不覆盖 ArkUI 搜索交互，实际键盘和列表布局待验收，未访问设备。
