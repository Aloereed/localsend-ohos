# M143 · 网页批量下载

版本 2.0.143 / 2000143。网页有文件可下载时显示“全部下载（ZIP）”，通过同一分享链接下的 archive.zip 下载全部非文字文件，单文件下载继续保留。简体中文、繁体中文、英文文案已添加。

ZIP 使用 [PKWARE ZIP 格式规范](https://pkware.cachefly.net/webdocs/casestudies/APPNOTE.TXT) 中的 stored ZIP64、UTF-8 文件名和 CRC32 数据描述符，按最多 64 KiB 的块读取并等待网络写入；只保存条目元数据，不将整批内容装入内存或写临时压缩包。ZIP 不压缩内容，体积约等于原文件总和。提取基础文件名并处理重名、路径和平台保留名，压缩包内为平铺文件。

服务复用当前下载确认/自动允许设置，一次确认对应整批压缩包。链接到期、停止分享、取消下载继续生效。应用任务显示 ZIP 总字节进度；任一源文件读取失败会中断整个下载，避免生成看似完整的残缺包。现有上传 PIN 处理不变。

web-batch 测试通过真实 HTTP/HTTPS 下载并调用独立 Python zipfile 解压，检查 CRC、中文及重复文件名、空文件和二进制内容；覆盖拒绝/接受、自动允许、活动取消、链接失效、空清单、短读取、源文件缺失/截短及 ZIP64 大于 4 GiB 的长度字段。大于 4 GiB 仅验证布局和字段，没有声称本轮传输了完整大文件。

web、web-page、web-language、web-template 回归通过。正式 release 编译及 APP/HAP 签名通过；未安装鸿蒙设备，实际移动浏览器保存流程待真机验证。自定义模板通过 PAGE 占位符嵌入默认页面时自动获得按钮；完全自定义页面可添加相对链接 archive.zip。
