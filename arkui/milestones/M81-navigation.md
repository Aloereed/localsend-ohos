# M81 · 返回与快捷跳转同步

消息自动打开、设备详情进入消息、接收页设置入口、收到分享后前往发送及返回接收页，统一调用 selectTab，同时更新选中状态和当前 HDS/普通 Tabs 控制器。原先这些入口仅修改状态变量，与底栏点击路径不同。

系统返回和屏幕返回按钮共用处理逻辑。等待 PIN 时优先取消该发送请求并释放输入等待；随后再次返回才执行页面导航。目录选择仍优先关闭。

真实 HTTP PIN 测试新增直接取消等待中的传输，验证无多余请求、发送映射归零、PIN 状态清空。ArkTS 和原生未签名构建通过。源码核对除控制器 onChange 外，程序跳转均使用统一方法。未访问设备；分页动画、HDS 底栏及系统键盘拦截返回的交互仍需实机检查。
