# M76 · 单文件重试

传输结果页为失败或取消的发送文件提供独立重试按钮，读屏标签包含文件名。完成、跳过以及已交给重试任务的文件不能重复发起请求。原任务正在重试时，其他重试按钮一起禁用。

每个文件记录其重试任务 ID。单文件重试后，整体“重试未完成文件”只选择仍未处理的文件，避免重复发送。只有原任务全部未完成文件均已交给新任务时，整体入口才显示已重试；失败的新任务仍可继续重试。

真实 HTTP 测试验证三文件首轮部分失败，单独重试第二项、批量补发第三项，再从失败的新任务重试第二项；四次请求清单精确匹配，不重新发送第一项。未知 ID、完成文件以及旧任务重复点击没有产生请求。服务集成回归测试同时通过，ArkTS 和原生未签名构建成功，未访问设备。

与 Flutter 相同地提供单文件操作，但原生重试仍重新请求接收方确认并创建新任务，不复用已终止的接收会话和令牌。
