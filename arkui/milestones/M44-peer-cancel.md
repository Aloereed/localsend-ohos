# M44 · 对方终止传输

接收取消接口同时处理本机发送会话，按对方 IP 和远端会话 ID 匹配，拒绝错误会话。取消立即释放正在等待的网络写入、关闭上传连接并将待发文件置为取消；收到远端取消不回发取消，避免互相通知。主动停止接收也会通知发送方。

验证：真实服务与浏览器集成回归通过。新增独立接收端暂停读取再发取消的测试，要求 1.5 秒内终止发送、后续文件取消、无取消回声、文件句柄归零，错误会话不能终止当前发送。ArkUI debug 构建通过。

产物：`artifacts/AloeSend-2000044-M44-peer-cancel-unsigned.hap`，版本 `2.0.44`。
