# M100 · 改名绑定接收会话

单文件及批量改名弹层记住打开时的接收任务 ID，提交时传给服务校验。原接收请求结束或被新请求替代时关闭弹层，原名提示也按已绑定任务读取。避免不同请求复用 f1 等文件 ID 时，旧编辑操作修改新的接收任务。

服务集成新增不匹配会话的单文件/批量改名拒绝断言，确认新任务名称不变，并验证当前会话提交成功。最终服务测试全部通过、未签名构建成功。未访问设备，弹层自动关闭效果仍待验收。
