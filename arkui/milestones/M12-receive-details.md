# M12 · 接收与文件详情

- 接收确认可为本次传输选择目录；接收副本保留文件夹层级，各次传输独立目录。
- 文件详情显示图片预览、大小、来源、时间、应用路径和另存路径，支持系统分享与另存为。
- 可在接收完成后自动进入对应会话，默认关闭。
- 关闭持久历史后，本次会话内容仍可查看；重新打开记录不会追溯保存临时内容。
- 设备名支持随机生成和系统型号；关于页提供版本、贡献者、完整 Apache 许可和项目链接。
- 版本名与 versionCode 在构建时同步，便于按版本回退检查。

验证：ArkUI 原生 debug 编译成功；16 组真实本机 TLS/HTTP 集成测试通过；新增历史持久化、单次目录及文件副本测试通过，文件描述符无泄漏。

限制：按用户要求未使用 DevEco 预览、签名或安装；系统选择器授权及实际界面效果待设备检查。主机测试只替代平台原语，不证明系统 API 在设备上的表现。
