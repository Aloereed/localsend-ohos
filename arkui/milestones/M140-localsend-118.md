# M140 · LocalSend 1.18 功能对齐

版本 2.0.140 / 2000140。基于 LocalSend v1.18.2 为原生鸿蒙应用补齐通用新增功能，并提供适合鸿蒙的平台入口。逐项范围与证据见 [功能清单](../localsend-1.18-feature-audit.md) 和 [平台对应](../platform-1.18.md)。

- SHA-256 默认生成和验证、进度与取消、422 最多三次上传；保留旧 hash 兼容及逐文件失败处理。
- RGB/Hex 自定义颜色、首次启动尊重系统动画设置、收藏设备默认自动接收并验证加密身份、长时间 ETA、TB/PB 大小及自定义目录重名避让。
- 网页目录拖放、IPv4/IPv6 HTTP/HTTPS、模板导入/导出/恢复及持久化。
- 鸿蒙桌面快捷操作、冷/热启动文本参数、计算校验和期间保持后台任务；保留已导入的新增语言。
- 包含 M137 的客户端 TLS 身份和系统手势条修复、M138 发现机制补齐、M139 文件持久授权恢复。

76 个测试文件完成验证。73 文件批次初次 70 通过、3 失败；修复动画初始值持久化及发送校验和失败影响整批的问题后，失败项与相关测试复测通过。两个新增测试和真实本机 IPv4/IPv6 原生组播测试单独通过。原始批次记录保留在 logs/M140-all-results.json，复测日志为 logs/M140-retest-*.log。

最终 release 编译通过，APP 和独立 HAP 签名验证通过。包路径、哈希及源码状态见 [交接记录](../HANDOFF.md)。尚未安装鸿蒙设备，跨端互操作、系统栏显示、重启后授权和快捷入口需真机验收。
