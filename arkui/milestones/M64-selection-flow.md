# M64 · 完整快捷选择与选择失败恢复

文件选择现在明确返回是否加入了新内容。取消、重复选择、空文件夹、读取失败、剪贴板权限拒绝或空白内容均不触发快捷发送。开始异步选择前保存目标设备并清理待发送目标，防止后续页面状态变化影响此次操作。

多文件和系统文件夹选择先读取全部元数据，成功后一次加入清单；子文件无法读取时不留下半个文件夹。原清单及文件引用保持不变，源 URI 去重。自定义下载目录选择器使用同样的结果语义。
