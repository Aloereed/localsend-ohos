# M50 · 取消通知时序与 TLS 关闭

接收端取消时立即结束本侧状态，优先发出 LocalSend 取消请求，再关闭数据连接，通知上限为一秒。修复发送方先收到断流而把取消误判为网络错误的竞态。两套真实服务通过 HTTP 和 HTTPS 双端取消测试，并能立即进行下一次传输。

TLS 正常关闭时补发 close_notify；增加确认接收、上传凭据、上传连接和首段数据的诊断日志。上述传输专项、128 MiB 校验和与编译均通过。

真机反馈：Windows LocalSend 重启后零进度恢复；多个 GiB 的文件仍会触发 32 MiB 接收缓冲上限。后续 M51 改为按落盘速度读取，不能将本包当作大文件问题已解决。

产物：`artifacts/AloeSend-2000050-M50-tls-close-notify-unsigned.hap`，版本 `2.0.50`。
