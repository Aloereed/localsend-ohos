# M55 · 接收会话状态与可用文件操作

接收请求通过协议校验后即建立稳定 ID 的历史记录，保留等待确认、拒绝、接收中、完成、跳过、取消和失败结果。重命名和选择部分文件后更新同一条记录；完成的文件继续可用，批次其余文件取消不会将成功项改为失败。

只有文件校验和最终重命名完成后，历史才获得可用路径。未完成或失败的文件在消息、历史和详情中不显示打开、分享、再次发送或另存操作；点击消息文件行可查看当前状态。文字预览仍可复制。正在接收时删除记录不会在完成后恢复，临时历史也不会因途中开启保存而被持久化。

对收发历史查找建立一次性映射，避免同批次文件逐项重复扫描完整历史。接收历史仅在阶段转换更新，不跟随进度每 100 ms 写盘。
