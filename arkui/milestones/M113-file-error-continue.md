# M113 · 接收方单文件错误后继续发送

接收方上传接口返回 HTTP 500 时，原生发送端原先抛出到整批异常处理，取消远程会话并跳过后续文件。现在将该文件标记为 error、保存具体错误和历史，然后继续后续文件。批次含失败项时最终保持 error，不提示全部发送成功。

此变更仅处理明确返回的上传 HTTP 500。无效会话、网络连接异常、用户或对方取消仍走终止路径。相同会话重试、接收端保留可恢复文件错误及其他异常分类尚未完成，不能称为 Flutter 重试语义全面对齐。

验证：真实 HTTP 接收端模拟四文件中的第二、第四项失败，第三项成功；检查历史、未发出整批 cancel、单文件/剩余失败项重试和成功文件不重发。全部 55 个主机测试通过，包括已有 HTTP/HTTPS 取消回归。最终 ArkTS/原生库构建成功；未访问鸿蒙设备。
