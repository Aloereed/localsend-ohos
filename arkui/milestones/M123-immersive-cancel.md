# M123 · 系统栏沉浸与取消通知

主窗口启用全屏布局，状态栏与导航栏透明；页面背景延伸至系统栏，内容按状态栏、挖孔和导航指示区域避让。浅色/深色主题同步系统栏文字颜色，监听区域变化，窗口销毁后解除回调。

取消通知此前仅等待 1 秒，接收致命错误的响应也可能抢在取消通知前结束上传，使 Flutter 离开发送状态后拒绝取消。本版将每次通知等待延长至 4 秒；v2 网络失败重试一次，保持原协议、证书检查和会话 ID。协议拒绝、身份变化及无会话 ID 的 v1 不重试。致命错误清理先等待通知，再返回错误响应。文件级可恢复 500 和明确取消语义保持区分。未收到确认时显示本端停止但对方未确认的提示。

加密开关保存后提示重启接收服务，并从 Windows 系统托盘退出 LocalSend 后重开；设置旁保留完整说明，包含旧连接可能导致 0% 进度的提示。新增文案含英文。

58 个主机测试全部通过（18.3 秒），ArkTS 构建通过。取消测试包括 HTTPS 确认延迟 1.3 秒、首次连接中断重试和致命错误响应顺序；既有 v1/v2 × HTTP/HTTPS 双端重试取消仍通过。窗口测试覆盖全屏、透明、主题切换、区域变化和销毁回调。未访问鸿蒙设备，也未声称已在用户的 Windows LocalSend 上验证修复。
