# M66 · 接收选择重置与确认后锁定

对照 Flutter 接收选项，重置操作同时恢复原文件名和全部选择，按钮明确标为“恢复选择和名称”。批量编号默认不补零，与 Flutter 默认值一致。批量操作按钮允许换行，避免长翻译在窄屏中挤出。

接收确认后，逐个文件的选择回调也必须拒绝修改，和批量选择/重命名已有的保护保持一致。防止旧界面回调改变已发给发送方的接收清单。

## 验证

- 本机真实 HTTP 接收验证改名/取消选择后重置，恢复全部选择及原名；再次选择子集并确认后，旧回调和重置均不能修改已确认清单。
- 接收历史和批量命名专项通过；最终 ArkTS 与未签名构建通过。
- 未连接设备，实际窄屏、大字体和按钮换行效果仍待检查。本轮未重跑无关的完整测试集。
