# M72 · 接收存储错误与恢复验证

接收初始化、写入、关闭和最终重命名遇到已知存储错误时，显示明确提示：空间不足、没有写入权限或只读目录。中文/英文均有对应文案，其他未知错误保留原信息。错误码依据本地 SDK `@ohos.file.fs.d.ts`：13900025、13900012、13900027。

## 验证

- 本机真实 HTTPS 上传先写入一个字节，再注入空间不足错误。接收和历史进入失败状态，无成功路径；临时文件移除、句柄归零、服务解除忙状态。
- 紧接着发起下一次请求并完成实际文件接收，内容一致。
- 服务集成测试共 28 组通过；ArkTS 与未签名构建通过。
- 本轮没有声称新增可用空间预检：容量可能在传输期间变化，仍通过真实写入错误结束并恢复会话。未连接设备，实际存储配额和授权变化仍待用户检查。
