# M68 · 多设备发送按身份选择

多选目标改用设备指纹作为优先标识，缺少指纹时才使用 IP/端口。设备改名或换地址后保持选择；相同 IP 换成另一身份不会继承旧勾选。附近列表与收藏中的同一身份只发送一次。

发送按钮数量和实际发送都使用相同的目标解析函数。附近设备优先提供当前端点，收藏可作为离线回退；已不在两种列表中的目标不计入数量，也不会启动空队列。设备列表节点包含身份信息，选中状态提供无障碍语义。

## 验证

- 专项验证改名/换地址、重复列表、离线收藏、目标消失、同 IP 不同身份、无指纹端点及新身份需要重选。
- 会话身份回归通过；ArkTS 与未签名构建通过。
- 未连接设备；真实局域网刷新过程的多选显示与多台发送仍待用户检查。
