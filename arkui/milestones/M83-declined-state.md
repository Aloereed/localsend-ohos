# M83 · 拒绝状态一致性

对端拒绝发送请求时，传输任务及文件改为 declined，与消息/历史一致，不再视作普通故障提供失败重试入口。用户仍可从发送页重新发起新请求。

接收确认被拒绝、取消或全部取消选择时，文件行同步到拒绝、取消或跳过状态，记录结束时间，避免任务已结束而文件仍显示等待确认。

真实协议测试验证发送拒绝的任务/文件/历史状态、拒绝任务不触发失败重试、接收明确拒绝和空选择的结果。服务集成、消息状态及双端取消三个测试文件通过，ArkTS 与原生未签名构建成功，未访问设备。
