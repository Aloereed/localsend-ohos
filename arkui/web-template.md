# 自定义浏览器分享页面

在“通过链接分享”页面、开始分享之前使用“导入网页”“导出模板”“恢复默认网页”。导入文件复制到应用内，重启后继续可用；当前分享启动后固定使用当时的模板。

支持 UTF-8 HTML，最大 2 MiB。导入失败或取消保留原模板。恢复默认只移除应用内模板副本。

模板可直接包含完整 HTML，也支持以下可选标记：

| 标记 | 内容 |
| --- | --- |
| `{{PAGE}}` | 当前内置分享页面，包括文件清单、上传、文字、语言选择及对应脚本 |
| `{{ALIAS}}` | 已做 HTML 转义的设备名称，用于普通文本或引号包裹的 HTML 属性 |

导出的默认模板含一个 PAGE 标记及样式区，可先修改样式。每次页面请求生成最新的内置页面，然后进行单次替换；设备名和插入的页面内出现的标记不会再次展开。ALIAS 不应用于 JavaScript 字符串等不同的语法上下文。

若整页自建，页面位于带令牌的 `/s/<token>/` 路径；上传 API 使用相对路径 `api/localsend/v2/prepare-upload`、`upload`、`cancel`，协议与内置页面相同。模板不会获得应用私有文件路径，也不会跳过服务端 PIN、接收确认、文件令牌和路径校验。

这是鸿蒙应用沙箱下的模板导入方式；本端发送和接收共用一个网页，因此用一个模板覆盖该页面。上游桌面端可执行文件旁的 web 目录和静态资源路径不直接适用于此应用。
