## 最新修复

- **M54–M55**：收发开始即建立消息记录，保留等待、进行中、完成、拒绝、失败、跳过和取消状态。失败文件无可用路径；删除和不保存历史的选择在传输完成后仍被尊重。重启会将本机未完成记录标为中断。
- **M51–M52**：HTTPS 接收按实际落盘速度读取，磁盘繁忙时通过 TCP 背压让发送端减速。3 GiB 主机测试经过一秒磁盘暂停后完成，SHA-256 一致，接收队列约 64 KiB；连接取消、阻塞发送退出与同端口重启回归通过。

- **M43–M49**：去掉圆形 Logo 下的方形背景；浮动底栏在 API 23+ 使用 HDS 系统材质；隐私政策直接同步 Flutter 内容；首次启动导入 Flutter 收藏、历史和消息；版本号只保留数字。
- **M47、M53**：无系统文件夹选择能力时使用下载目录内的选择器，补齐系统运行时报告不支持的情况。

## 明早建议检查

2. 前台静置，应自动发现附近设备。发送大文件过来，确认接收后进入进度页；进度平稳更新，完成后文件可打开，下载目录内容完整。

4. 检查浅/深色、平板侧栏与窄窗口底栏、横向发送入口、下拉选中值、高级设置开关、顶部提示自动消失。
